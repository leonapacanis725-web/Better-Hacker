BEGINNER LINUX SECURITY GUIDE

Linux File Permissions 0644 vs 0600

Linux permissions control who can read, write, or execute a file. Choosing restrictive permissions helps reduce accidental exposure of sensitive information.

What do the numbers mean?

Each octal digit represents permissions for a different class: owner, group, and others. Read is 4, write is 2, and execute is 1. Add the values to combine permissions.

0644 explained

0644 means the owner can read and write (6), while group members and others can read (4 and 4). It is common for non-sensitive text files that should be publicly readable by local users, but it is not appropriate for every file.

0600 explained

0600 means the owner can read and write (6), while group and others have no permissions (0 and 0). This is a safer starting point for files containing private keys or other sensitive data, subject to the application’s requirements.

Inspect before changing

ls -l filename
stat -c '%a %n' filename

These commands inspect permissions. If a change is authorized and needed, chmod 600 filename sets owner read/write only. Confirm the correct path and service requirements first; changing permissions can break legitimate access.

Security takeaway

Use the least access required, check ownership as well as mode bits, and never assume a permission value is secure without considering how the file is used.
