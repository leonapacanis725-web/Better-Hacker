BEGINNER WEB SECURITY GUIDE

Use curl to Inspect TLS and Security Headers

curl is a command-line tool for transferring data. Defenders can use it to inspect responses from a site they own or have permission to assess. These examples make ordinary read-only requests.

Inspect response headers

curl -I https://example.com

-I requests response headers without downloading the response body. Review the HTTP status and headers such as Strict-Transport-Security, Content-Security-Policy, X-Content-Type-Options, and Referrer-Policy. A missing header is a review item, not automatic proof of a vulnerability.

Inspect TLS connection details

curl -Iv https://example.com

-v prints connection and TLS negotiation details. Use it to observe the negotiated protocol and certificate information. Do not use options that skip certificate verification as a normal security check; verification is part of the protection TLS provides.

What to record

  • Target hostname and authorization/scope.
  • Date and time of the check.
  • HTTP status and relevant response headers.
  • TLS version and certificate validation result.
  • Limitations, browser-specific behavior, and recommended owner follow-up.

Keep testing in scope

Do not scan or probe websites without permission. Use a lab, your own site, or a written authorized scope. Save only the minimum evidence needed and remove secrets before sharing a report.
